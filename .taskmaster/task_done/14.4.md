# 任务 14.4 MflS (过滤、排序和搜索) 功能开发计划

**目标**: 为 `Exercise` 和 `StudentAnswer` 两个模型的API端点实现过滤、排序和搜索功能。

**核心工具**:
- `django-filter`
- `Django REST Framework`

**相关文件**:
- `a7/courses/views.py`
- `a7/courses/tests/test_api_exercises.py`
- `a7/a7/settings.py`
- `requirements.txt`

---

## 详细计划步骤

### 1. 环境配置
- **安装依赖**: 在 `requirements.txt` 文件中添加 `django-filter`。
  ```
  ...
  django-filter
  ...
  ```
- **更新Django设置**: 
  - 在 `a7/a7/settings.py` 的 `INSTALLED_APPS` 中注册 `'django_filters'`。
  - 在 `REST_FRAMEWORK` 配置中，设置 `'DEFAULT_FILTER_BACKENDS'` 为 `['django_filters.rest_framework.DjangoFilterBackend']`。

### 2. `ExerciseViewSet` 功能增强
- **位置**: `a7/courses/views.py`
- **操作**:
  1. 导入 `SearchFilter` 和 `OrderingFilter`。
     ```python
     from rest_framework import filters
     ```
  2. 在 `ExerciseViewSet` 中配置 `filter_backends`，启用过滤、搜索和排序功能。
     ```python
     filter_backends = [filters.SearchFilter, filters.OrderingFilter, DjangoFilterBackend]
     ```
  3. 定义 `filterset_fields` 以支持按 `question_type` (问题类型) 和 `knowledge_point` (知识点) 进行过滤。
     ```python
     filterset_fields = ['question_type', 'knowledge_point']
     ```
  4. 定义 `search_fields` 以支持按 `question_text` (问题文本) 进行全文搜索。
     ```python
     search_fields = ['question_text']
     ```
  5. 定义 `ordering_fields` 以支持按 `creation_date` (创建日期) 和 `id` 排序。
     ```python
     ordering_fields = ['creation_date', 'id']
     ```

### 3. `StudentAnswerViewSet` 功能增强
- **位置**: `a7/courses/views.py`
- **操作**:
  1. 在 `StudentAnswerViewSet` 中配置 `filter_backends`，启用过滤和排序。
     ```python
     filter_backends = [filters.OrderingFilter, DjangoFilterBackend]
     ```
  2. 定义 `filterset_fields` 以支持按 `student` (学生) 和 `exercise` (练习题) 进行过滤。
     ```python
     filterset_fields = ['student', 'exercise']
     ```
  3. 定义 `ordering_fields` 以支持按 `answer_date` (答题日期) 排序。
     ```python
     ordering_fields = ['answer_date']
     ```
  
### 4. 编写和执行测试
- **位置**: `a7/courses/tests/test_api_exercises.py`
- **操作**:
  - **准备测试数据**: 创建多个 `Exercise` 和 `StudentAnswer` 实例，确保它们有不同的属性值（如不同的 `question_type`、`knowledge_point` 和 `creation_date`）。
  - **测试 `Exercise` 过滤**:
    - 发送GET请求到 `/api/exercises/`，附加查询参数 `?question_type=single-choice`。
    - 验证响应中只包含指定类型的练习。
    - 对 `knowledge_point` 进行类似测试。
  - **测试 `Exercise` 排序**:
    - 发送GET请求，附加查询参数 `?ordering=-creation_date`。
    - 验证响应中的练习是按创建日期降序排列的。
  - **测试 `Exercise` 搜索**:
    - 发送GET请求，附加查询参数 `?search=keyword` (keyword是问题文本中的关键词)。
    - 验证响应中只包含 `question_text` 匹配该关键词的练习。
  - **测试 `StudentAnswer`**:
    - 对 `StudentAnswerViewSet` 的过滤和排序功能编写并执行类似的测试。
