# 课件文件上传API实现计划 (任务19.3)

## 需求概述

实现一个API端点（`POST /api/courseware/upload/`）用于教师上传课件文件，包括文件验证（类型、大小）并将上传的文件与正确的课件条目关联。

## 前置条件分析

已完成的依赖任务：
1. 任务19.1：已扩展Courseware模型，添加了CoursewareFile模型存储文件元数据
2. 任务19.2：已配置文件存储后端，实现了文件名唯一化和按课程/文件类型组织文件结构

## 技术方案

### 1. API端点设计

- **URL路径**：`/api/courseware/upload/`
- **HTTP方法**：POST
- **权限要求**：仅教师和管理员可访问
- **请求参数**：
  - `courseware_id`：必填，课件ID，用于关联上传的文件
  - `file`：必填，文件对象
- **响应格式**：
  ```json
  {
    "success": true,
    "data": {
      "id": 1,
      "file_name": "example.pdf",
      "file_size": 1024,
      "file_type": "application/pdf",
      "file_url": "/media/coursewares/1/pdfs/uuid-example.pdf",
      "upload_time": "2025-07-18T10:30:00Z"
    }
  }
  ```

### 2. 序列化器设计

需要创建两个序列化器：
1. `CoursewareFileUploadSerializer`：处理文件上传请求
2. `CoursewareFileSerializer`：返回文件信息

### 3. 实现步骤

1. **创建序列化器**：
   - 在 `courses/serializers.py` 中添加新的序列化器类

2. **扩展CoursewareViewSet**：
   - 在 `courses/views.py` 中的 `CoursewareViewSet` 类中添加文件上传动作
   - 实现权限检查，确保只有教师和管理员可以上传文件
   - 实现文件处理和保存逻辑

3. **添加API文档**：
   - 使用Swagger装饰器添加API文档
   - 定义请求参数和响应格式

4. **实现错误处理**：
   - 处理文件类型无效的情况
   - 处理文件大小超限的情况
   - 处理课件不存在的情况
   - 处理权限不足的情况

#### 4.1 添加序列化器（courses/serializers.py）

```python
class CoursewareFileUploadSerializer(serializers.Serializer):
    """课件文件上传序列化器"""
    courseware_id = serializers.IntegerField(required=True)
    file = serializers.FileField(required=True)
    
    def validate_courseware_id(self, value):
        """验证课件ID是否存在"""
        try:
            Courseware.objects.get(id=value)
        except Courseware.DoesNotExist:
            raise serializers.ValidationError(_("指定的课件不存在"))
        return value
    
    def validate_file(self, value):
        """验证文件类型和大小"""
        # 获取允许的文件类型和最大大小
        allowed_types = getattr(settings, 'ALLOWED_FILE_TYPES', [])
        max_size_mb = getattr(settings, 'MAX_FILE_SIZE_MB', 10)
        
        # 验证文件类型
        if not validate_file_type(value, allowed_types):
            raise serializers.ValidationError(_("不支持的文件类型"))
        
        # 验证文件大小
        if not validate_file_size(value, max_size_mb):
            raise serializers.ValidationError(_(f"文件大小超过限制（最大{max_size_mb}MB）"))
        
        return value

class CoursewareFileSerializer(serializers.ModelSerializer):
    """课件文件序列化器，用于返回文件信息"""
    file_url = serializers.SerializerMethodField()
    
    class Meta:
        model = CoursewareFile
        fields = ['id', 'file_name', 'file_size', 'file_type', 'file_url', 'upload_time']
        read_only_fields = ['id', 'file_name', 'file_size', 'file_type', 'upload_time']
    
    def get_file_url(self, obj):
        """获取文件URL"""
        return obj.get_file_url()
```

#### 4.2 扩展CoursewareViewSet（courses/views.py）

```python
@swagger_auto_schema(
    operation_summary="上传课件文件",
    operation_description="上传文件并关联到指定的课件",
    request_body=CoursewareFileUploadSerializer,
    responses={
        201: CoursewareFileSerializer,
        400: "请求参数无效",
        403: "权限不足",
        404: "课件不存在"
    }
)
@action(detail=False, methods=['post'], permission_classes=[IsTeacherOrAdmin])
def upload(self, request):
    """
    上传课件文件并关联到指定的课件
    """
    serializer = CoursewareFileUploadSerializer(data=request.data)
    if not serializer.is_valid():
        return Response(
            create_api_response(
                success=False,
                error_code="VALIDATION_ERROR",
                message=_("参数验证失败"),
                errors=serializer.errors,
                status_code=status.HTTP_400_BAD_REQUEST
            ),
            status=status.HTTP_400_BAD_REQUEST
        )
    
    # 获取课件
    try:
        courseware_id = serializer.validated_data['courseware_id']
        courseware = Courseware.objects.get(id=courseware_id)
    except Courseware.DoesNotExist:
        return Response(
            create_api_response(
                success=False,
                error_code="NOT_FOUND",
                message=_("课件不存在"),
                status_code=status.HTTP_404_NOT_FOUND
            ),
            status=status.HTTP_404_NOT_FOUND
        )
    
    # 验证用户是否有权限上传文件到此课件
    if courseware.course.teacher != request.user and not request.user.is_staff:
        return Response(
            create_api_response(
                success=False,
                error_code="PERMISSION_DENIED",
                message=_("您没有权限上传文件到此课件"),
                status_code=status.HTTP_403_FORBIDDEN
            ),
            status=status.HTTP_403_FORBIDDEN
        )
    
    # 创建文件记录
    try:
        file = serializer.validated_data['file']
        courseware_file = CoursewareFile.objects.create(
            courseware=courseware,
            file=file
        )
        
        # 返回文件信息
        response_serializer = CoursewareFileSerializer(courseware_file)
        return Response(
            create_api_response(
                success=True,
                data=response_serializer.data,
                status_code=status.HTTP_201_CREATED
            ),
            status=status.HTTP_201_CREATED
        )
    except Exception as e:
        return Response(
            create_api_response(
                success=False,
                error_code="UPLOAD_ERROR",
                message=_("文件上传失败"),
                errors=[str(e)],
                status_code=status.HTTP_500_INTERNAL_SERVER_ERROR
            ),
            status=status.HTTP_500_INTERNAL_SERVER_ERROR
        )
```

### 6. 安全考虑

1. **文件类型验证**：严格限制允许的文件类型，防止上传恶意文件
2. **文件大小限制**：防止服务器资源耗尽
3. **权限控制**：确保只有授权用户可以上传文件
4. **文件名处理**：使用UUID生成唯一文件名，防止路径遍历攻击
5. **存储路径安全**：按课程ID和文件类型组织文件，隔离不同课程的文件
