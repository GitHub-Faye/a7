# 任务19.4实现计划 - 文件下载API实现

## 任务概述

实现课件文件下载API，允许授权用户下载上传的课件文件。API应提供合适的权限检查，确保只有授权用户（如已注册学生）能够访问文件。

## 相关任务和依赖项分析

- **已完成的任务:**
  - 任务19.1: 扩展Courseware模型，添加CoursewareFile模型用于存储文件元数据
  - 任务19.2: 配置文件存储后端，实现文件名唯一化和按课程/文件类型组织文件
  - 任务19.3: 实现文件上传API，支持将文件关联到课件

- **当前任务相关组件:**
  - CoursewareFile模型: 包含文件元数据和文件访问方法
  - CoursewareViewSet: 已实现上传API，需要扩展添加下载API
  - 权限控制: 需要集成现有的权限系统确保安全访问

## 实现方案

### 1. API端点设计

- **路由:** `/api/courseware/download/<file_id>/`
- **方法:** GET
- **权限:** 已认证用户（登录用户）
- **功能:** 根据file_id获取并返回对应的文件

### 2. 权限控制设计

实现两层权限控制：
1. **基本认证:** 确保用户已登录（使用IsAuthenticated权限类）
2. **业务逻辑权限:** 验证用户是否有权限访问特定文件
   - 课程教师可以访问其所有课程的文件
   - 管理员可以访问所有文件
   - 学生只能访问已注册课程的文件

### 3. 实现步骤

1. 在CoursewareViewSet中添加download动作方法
2. 实现文件获取和验证逻辑
3. 实现权限检查
4. 添加适当的错误处理
5. 配置文件流式响应
6. 添加文档注解（使用swagger_auto_schema）
7. 编写测试用例

### 4. 代码实现

```python
@swagger_auto_schema(
    operation_summary="下载课件文件",
    operation_description="下载指定ID的课件文件",
    responses={
        200: "文件下载",
        403: "权限不足",
        404: "文件不存在"
    }
)
@action(detail=False, methods=['get'], url_path='download/(?P<file_id>[^/.]+)')
def download(self, request, file_id=None):
    """
    下载课件文件
    """
    try:
        # 查找文件
        courseware_file = CoursewareFile.objects.get(id=file_id)
        
        # 权限检查
        user = request.user
        courseware = courseware_file.courseware
        course = courseware.course
        
        # 检查用户是否有权限访问
        if not (
            user.is_staff or                           # 管理员
            course.teacher == user or                  # 课程教师
            user.enrolled_courses.filter(id=course.id).exists()  # 已注册学生
        ):
            return create_api_response(
                success=False,
                error_code="PERMISSION_DENIED",
                message=_("您没有权限下载此文件"),
                status_code=status.HTTP_403_FORBIDDEN
            )
        
        # 获取文件路径
        file_path = courseware_file.file.path
        
        # 检查文件是否存在
        if not os.path.exists(file_path):
            return create_api_response(
                success=False,
                error_code="FILE_NOT_FOUND",
                message=_("文件不存在或已被删除"),
                status_code=status.HTTP_404_NOT_FOUND
            )
        
        # 返回文件流
        content_type = courseware_file.file_type or 'application/octet-stream'
        response = FileResponse(open(file_path, 'rb'), content_type=content_type)
        response['Content-Disposition'] = f'attachment; filename="{courseware_file.file_name}"'
        return response
        
    except CoursewareFile.DoesNotExist:
        return create_api_response(
            success=False,
            error_code="FILE_NOT_FOUND",
            message=_("文件不存在"),
            status_code=status.HTTP_404_NOT_FOUND
        )
    except Exception as e:
        return create_api_response(
            success=False,
            error_code="DOWNLOAD_ERROR",
            message=_("文件下载失败"),
            errors=[str(e)],
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR
        )
```
