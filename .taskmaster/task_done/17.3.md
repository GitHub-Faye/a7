
# 任务17.3 - 实现答案校正机制计划（修订版）

## 任务概述
实现学生答案校正机制，使用AI服务评估学生提交的答案并提供反馈。

## 背景分析
- 系统中已实现学生助手对话功能(任务17.1)和练习题生成功能(任务17.2)
- 练习题生成功能通过n8n AI服务生成不同类型的练习题(单选、多选、简答等)
- 目前尚无答案校正/评价机制，无法自动评估学生提交的答案
- **注意：N8N服务只接受chatInput和sessionId两个输入，只输出answer一个结果**

## 现有相关代码分析
1. **AI服务视图实现**:
   - `StudentDialogueViewSet`: 处理学生对话请求，构造chatInput发送给N8N
   - `ExerciseGenerationViewSet`: 生成练习题，同样通过chatInput传递所有参数

2. **客户端交互**:
   - `N8nWebhookClient`: 提供与n8n服务通信的方法，所有请求格式一致
   - 所有方法都遵循相同模式：构造包含chatInput的请求数据并解析answer响应

3. **数据模型**:
   - `Exercise`: 包含练习题内容、类型、答案模板等
   - `StudentAnswer`: 记录学生提交的答案、得分和反馈

4. **序列化器**:
   - `StudentAnswerSerializer`: 读取学生答案
   - `StudentAnswerCreateSerializer`: 创建学生答案
   - `StudentAnswerUpdateSerializer`: 更新答案内容
   - `StudentAnswerFeedbackSerializer`: 提供评分和反馈

## 开发计划

### 1. 定义数据模型和格式
- 在`formats.py`中创建`AnswerCorrectionResponseData`模型
- 响应数据包含：正确性评估、得分、反馈建议、改进方向
- **不需要创建单独的请求模型，而是遵循N8N服务接口规范**

### 2. 添加客户端方法
- 在`N8nWebhookClient`中添加`correct_student_answer`和`correct_student_answer_sync`方法
- **关键点：方法内部将所有必要信息（练习题内容、学生答案等）整合到chatInput字段中**
- 使用结构化prompt模板，确保AI能够准确理解任务和数据

### 3. 创建序列化器
- 开发`StudentAnswerCorrectionSerializer`，用于处理答案校正请求
- 包括练习题ID、学生答案内容、会话ID等字段
- 添加验证方法确保数据有效

### 4. 实现API视图集
- 创建`StudentAnswerCorrectionViewSet`处理答案校正请求
- 实现`create`方法接收学生答案并转发给AI服务
- **关键点：将练习题详情、答案模板和学生答案组合成结构化prompt**
- 处理响应并返回格式化的评估结果
- 设置权限允许匿名访问

### 5. 注册URL路由
- 在`urls.py`中注册`StudentAnswerCorrectionViewSet`
- 提供`/api/correct-answer/`端点

### 6. 响应处理和格式化
- 实现`format_answer_correction_response`处理AI返回的答案评估
- **关键点：从纯文本answer字段中提取结构化数据（得分、反馈等）**
- 参考`format_exercise_generation_response`和`format_student_dialogue_response`
- 实现健壮的文本解析和JSON提取逻辑
- 处理边缘情况和错误情况

### 7. 编写测试
- 单元测试：测试序列化器、客户端方法和格式化函数
- 集成测试：测试完整的校正流程，包括与真实n8n服务的交互
- 测试不同题型的答案校正
- **测试复杂响应的解析能力**

## 技术要点
1. **Prompt工程**:
   - 设计结构化prompt模板，包含所有必要信息
   - 明确指示AI如何格式化答案评估结果
   - 根据题型（单选、多选、填空、简答）调整prompt策略

2. **响应解析**:
   - 从纯文本answer中提取JSON或结构化数据
   - 处理各种格式的答案评估结果
   - 实现健壮的错误处理和回退机制

3. **评分机制**:
   - 在prompt中明确评分标准和范围
   - 指导AI生成标准化评分和反馈

4. **反馈生成**:
   - 在prompt中要求AI提供具体、有帮助的改进建议
   - 确保反馈格式一致，便于前端展示

5. **错误处理**:
   - 处理AI服务连接问题
   - 应对无法评估的情况提供备选响应
   - 处理格式异常的响应
