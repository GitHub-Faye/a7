# Task ID: 15
# Title: Create Web API for marp-cli Markdown to Presentation Conversion
# Status: done
# Dependencies: 5, 6, 13
# Priority: medium
# Description: Develop a RESTful API that wraps marp-cli to convert Markdown content into various presentation formats (PDF, PPTX, HTML, PNG) with optional themes and proper error handling.
# Details:
1. **Dependency Installation**: Install marp-cli as a project dependency using npm or yarn.
2. **Service Layer**: Implement a Python service layer to interact with marp-cli via subprocess calls. This layer should handle:
   - Command-line argument construction for marp-cli (e.g., output format, theme).
   - Temporary file management (create input Markdown files and clean up after conversion).
3. **API Design**: Design REST API endpoints with the following specifications:
   - POST `/convert`: Accepts Markdown content, output format (PDF, PPTX, HTML, PNG), and optional theme.
   - Validates input parameters and returns appropriate HTTP status codes for errors.
4. **File Handling**: Implement logic to:
   - Create temporary Markdown files from input content.
   - Execute marp-cli to generate the output file.
   - Clean up temporary files post-conversion.
5. **Response Handling**: Return the converted file as a downloadable response with the correct MIME type.

**Considerations**:
- Ensure thread safety for concurrent API requests.
- Handle large file uploads efficiently.
- Implement rate limiting if necessary.

# Test Strategy:
1. **Unit Tests**:
   - Test the Python service layer for correct command-line argument generation and file handling.
   - Verify temporary file creation and cleanup.
2. **Integration Tests**:
   - Simulate API requests with various Markdown inputs, formats, and themes.
   - Validate response headers and file correctness.
3. **Error Handling**:
   - Test invalid inputs (e.g., unsupported formats, malformed Markdown) and verify appropriate HTTP status codes.
4. **Performance Tests**:
   - Measure conversion time for large Markdown files.
   - Check resource usage during concurrent requests.
