# Task ID: 18
# Title: Implement Student Learning Progress Tracking Module
# Status: pending
# Dependencies: 3, 14
# Priority: high
# Description: Develop a module to track and record student learning progress, including completion status of knowledge points and courses, as well as correctness statistics for exercises.
# Details:
1. **Database Integration**: Extend the existing database models (from Task 3) to include fields for tracking student progress, such as `is_completed` for knowledge points and courses, and `correctness_rate` for exercises. Ensure these fields are updated dynamically based on student activity.
2. **Progress Tracking Logic**: Implement logic to:
   - Update the `is_completed` flag for a knowledge point when all associated exercises are completed by the student.
   - Mark a course as completed when all its knowledge points are marked as completed.
   - Calculate and store the correctness rate for each knowledge point based on student answers (from Task 14).
3. **API Endpoints**: Create RESTful API endpoints to:
   - Fetch a student's progress for a specific course or knowledge point.
   - Retrieve correctness statistics for exercises within a knowledge point.
   - Trigger progress updates when a student completes an exercise.
4. **Permissions**: Ensure the API endpoints enforce role-based access (e.g., students can only view their own progress, teachers can view all students' progress).
5. **Error Handling**: Implement robust error handling for cases like invalid student IDs, missing knowledge points, or incomplete data.

# Test Strategy:
1. **Unit Testing**:
   - Test the progress tracking logic with various scenarios (e.g., partial completion, full completion, edge cases like no exercises).
   - Verify correctness rate calculations with different sets of student answers.
2. **Integration Testing**:
   - Simulate API requests to fetch and update progress, ensuring the responses match expected data.
   - Test permissions by attempting to access progress data with different user roles.
3. **End-to-End Testing**:
   - Simulate a student completing exercises and verify the system updates progress and correctness rates correctly.
   - Ensure the course completion flag is triggered only when all knowledge points are completed.
