# Task ID: 17
# Title: Create Student Assistant Module with AI Dialogue and Exercise Generation
# Status: done
# Dependencies: 13, 14
# Priority: medium
# Description: Develop a student assistant module that leverages n8n's AI service for dialogue and generates exercises on demand without database persistence, including answer correction functionality.
# Details:
1. **AI Dialogue Integration**: Utilize n8n's AI service to enable conversational interactions with students. Implement an API endpoint to handle student queries and forward them to the AI service, ensuring responses are contextually relevant and formatted appropriately.
2. **Exercise Generation**: Develop functionality to generate exercises based on student requests (e.g., topic, difficulty). Use the AI-powered question generation module (Task 13) to create exercises dynamically, ensuring they are not persisted in the database.
3. **Answer Correction**: Implement logic to evaluate student-submitted answers against the generated exercises. Leverage the AI service to provide feedback or corrections, ensuring accuracy and helpfulness.
4. **Temporary Data Handling**: Design the module to manage temporary data (e.g., generated exercises, student answers) in memory or transient storage, avoiding database persistence.
5. **Error Handling**: Ensure robust error handling for AI service failures, invalid inputs, or unexpected student interactions.

# Test Strategy:
1. **Unit Testing**:
   - Test the AI dialogue endpoint with various student queries to verify correct forwarding and response handling.
   - Validate exercise generation logic with different parameters (e.g., topics, difficulty levels).
   - Test answer correction functionality with correct and incorrect student submissions.
2. **Integration Testing**:
   - Simulate a full student interaction flow, including querying the assistant, generating exercises, and submitting answers for correction.
   - Verify temporary data is not persisted in the database.
3. **Error Testing**:
   - Test error handling for scenarios like AI service downtime or invalid student inputs.
