# Task ID: 19
# Title: Refactor AI Service Integration with Custom Prompt Support
# Status: pending
# Dependencies: 13, 17
# Priority: medium
# Description: Refactor the existing AI service integration to create a unified interface, maintaining RAG AI functionality while adding support for custom prompts to control AI response style, format, and content focus.
# Details:
1. **Unified Interface Design**: Create a new Python class or module to serve as a unified interface for AI service interactions. This interface should encapsulate the existing RAG AI functionality (sessionId and chatInput as input, answer and sources as output) while exposing methods for custom prompt injection.
2. **Custom Prompt Integration**: Extend the interface to accept an optional `custom_prompt` parameter. When provided, this prompt should override or augment the default RAG AI prompt, allowing developers to tailor the AI's response.
3. **Backward Compatibility**: Ensure the refactored interface remains backward-compatible with existing RAG AI calls. Default behavior should match the current implementation when no custom prompt is provided.
4. **Knowledge Base Query Preservation**: Maintain the existing knowledge base query functionality, ensuring it integrates seamlessly with custom prompts.
5. **Error Handling**: Implement robust error handling for invalid or malformed prompts, ensuring graceful degradation to default behavior when necessary.
6. **Documentation**: Update API documentation to include the new custom prompt feature, with examples of usage and expected outcomes.

# Test Strategy:
1. **Unit Testing**:
   - Test the unified interface with default RAG AI inputs to verify backward compatibility.
   - Validate custom prompt functionality by injecting prompts and comparing responses to expected outputs.
   - Test edge cases, such as empty or malformed prompts, to ensure graceful handling.
2. **Integration Testing**:
   - Simulate API calls to the refactored interface, including both default and custom prompt scenarios.
   - Verify that knowledge base queries still function correctly when custom prompts are used.
3. **Performance Testing**:
   - Measure response times with and without custom prompts to ensure no significant performance degradation.
