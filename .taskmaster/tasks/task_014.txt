# Task ID: 14
# Title: Implement CRUD APIs for Exercise and StudentAnswer Models
# Status: done
# Dependencies: 3, 4, 5
# Priority: high
# Description: Develop RESTful API endpoints for the Exercise and StudentAnswer models, including serializers, viewsets, and routing, with proper permissions, filtering, sorting, and search functionality.
# Details:
1. **Serializers**: Create serializers for the Exercise and StudentAnswer models to handle data validation and transformation. Ensure the Exercise serializer includes fields for question types (single-choice, multiple-choice, fill-in-the-blank) and knowledge point associations. The StudentAnswer serializer should link to both the student and the exercise.

2. **Viewsets**: Implement viewsets for both models, leveraging Django REST Framework's ModelViewSet for CRUD operations. Include custom permission classes to restrict access:
   - Teachers can create, update, and delete exercises.
   - Students can only view exercises and submit/modify their own answers.

3. **Routing**: Configure URL routing for the viewsets, ensuring endpoints are RESTful and follow naming conventions (e.g., `/api/exercises/`, `/api/student-answers/`).

4. **Filtering, Sorting, and Search**: Add filtering (e.g., by knowledge point, question type), sorting (e.g., by creation date), and search (e.g., by question text) capabilities using Django REST Framework's built-in tools.

5. **Testing**: Write unit tests for serializers, viewsets, and permissions. Include integration tests to verify API endpoints and permissions under various scenarios.

# Test Strategy:
1. **Unit Tests**:
   - Test serializer validation for both models.
   - Verify permission classes enforce correct access rules.
   - Test filtering, sorting, and search functionality.

2. **Integration Tests**:
   - Simulate API requests to ensure CRUD operations work as expected.
   - Test edge cases (e.g., invalid inputs, unauthorized access).
   - Verify filtering, sorting, and search responses.

3. **Manual Testing**:
   - Use tools like Postman to manually test endpoints.
   - Verify permissions by logging in as different user roles (teacher, student).
